# Show Top-Rated Groups on a Page

**Included in Free**

Add the shortcode to any page or post:

```
[bgr_display_top_groups title="Top groups" total_groups="10" type="top rated"]
```

Use `type="most reviewed"` to rank by number of reviews. See [Shortcodes and Widgets](../shortcodes/shortcodes-and-widgets.md) for every option.
