# Shortcodes and Widgets

**Included in Free**

## Shortcodes

### [add_group_review_form]

Shows the review form for the current group. Use it on a group page that supports shortcodes. It takes no attributes.

### [bgr_display_top_groups]

A leaderboard of groups.

| Attribute | Default | Values |
|-----------|---------|--------|
| `title` | empty | Heading above the list. |
| `total_groups` | 10 | Number of groups. |
| `type` | top rated | `top rated` or `most reviewed`. |
| `show_avatar` | true | `true` or `false`. |
| `show_rating` | true | `true` or `false`. |

## Widgets

- **BP Group Review Widget** - latest reviews. Set the title, number of reviews and the default rating filter.
- **BP Displayed Group Rating Widget** - the current group's reviews with Latest, Highest and Lowest filters. Place it in a group sidebar.
