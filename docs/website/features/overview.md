# Features Overview

**Included in Free**

Group Reviews adds a reputation layer to BuddyPress groups.

- Members post a written review and rate the group on every criterion you define.
- Group admins and site admins approve or deny each review, or you can auto approve.
- The average rating shows in the group header, the groups directory and a leaderboard.
- Ratings are published as Schema.org markup so search engines can show group scores.
- Members and group admins get notifications and optional emails.
- Reviews can post to the activity stream.
- A CSV export, two widgets, two shortcodes and a REST API are included.
