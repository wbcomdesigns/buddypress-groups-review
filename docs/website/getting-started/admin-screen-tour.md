# Admin Screen Tour

**Included in Free**

All settings live at **WB Plugins > Group Reviews**. Every tab saves on its own and takes effect on the next page load.

## Tabs

| Tab | What it controls |
|-----|------------------|
| Welcome | Short introduction and links to the documentation. |
| General | Multiple reviews, auto approval, reviews per page, notifications, activity posts, group-level criteria, excluded groups. |
| Criteria | The site-wide list of rating criteria. |
| Display | The review labels and the star color. |
| Emails | The three review emails: submission, acceptance, denial. |
| Discover | Other Wbcom Designs plugins that fit a community site. |

## Reviews list

Every review is also a row under **Reviews** in the admin menu. A badge shows how many are waiting for approval. You can approve, deny or delete reviews there one at a time or in bulk.

## Who can open the settings

Users with the `manage_options` capability. Developers can change this with the `bgr_admin_capability` filter.
