# Settings Reference

**Included in Free**

## General

| Setting | Default | What it does |
|---------|---------|--------------|
| Enable Multiple Reviews | Off | Lets a member review the same group more than once. |
| Auto Approval of Reviews | Off | Publishes reviews without approval. |
| Reviews Per Page | 5 | Reviews on each page of the Reviews tab. Allowed range 1 to 100; a blank, zero or negative value falls back to 5. |
| BuddyPress Notifications | On | Notifies group admins and reviewers. |
| Review Activity | On | Posts approved reviews to the activity stream. |
| Group-Level Criteria | Off | Lets group admins customize criteria. |
| Exclude Groups | None | Groups without reviews. |

## Criteria

The site-wide list of rating criteria. Default: Quality, Relevance, Engagement.

## Display

| Setting | What it does |
|---------|--------------|
| Review Label | Singular name, for example "Review". |
| Reviews Label (Plural) | Plural name, used for the group tab and its address. |
| Rating Color | Color of the stars. |

## Emails

Submission, acceptance and denial emails, each with an on/off switch, subject and message.
