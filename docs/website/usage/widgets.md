# Rating Widgets

The plugin registers two widgets for showing group ratings in sidebars, footers, or any widget area (Appearance, Widgets, or the block widget editor).

## Single Group Rating widget

Shows the average rating for a single group. Use it in a group-context sidebar to surface that group's rating outside the Reviews tab.

## Group Review widget

Lists group reviews or average ratings, so members can see recent or top-rated group feedback from a sidebar or footer.

## Notes

- Widgets read the same published-review data as the Reviews tab and the directory rating, so their numbers match.
- The star colour follows the **Rating star colour** set on the Display settings tab.

For placing the review form or a leaderboard directly in page content, use the [Shortcodes](../shortcodes/shortcodes.md) instead.
