== Description ==

This plugin allows the BuddyPress Memebers to add reviews to the buddypress groups on the site. The review form allows the users to even rate the group out of 5 points. 

If you need additional help you can contact us for [Custom Development](https://wbcomdesigns.com/contact/).

== Installation ==

1. Upload the entire "review-bp-grps" folder to the /wp-content/plugins/ directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.

== Frequently Asked Questions ==

= How can we sumit review to a group by using this plugin? =
 
When visiting the "/groups" section in the site, go for single group view page, there you can see a menu namely, "Reviews" that will allow you (if you're a site member) to add group review.

= What does the admin settings mean? =
 
The admin settings modifies the review creation template. If the popup allowed is checked, the form is will appear in a popup, otherwise the form will toggle on the same page.
