# Installation & Setup Tutorial Video Script

**Title:** How to Set Up BuddyPress Group Reviews
**Duration:** 4:00 - 5:00 minutes
**Purpose:** Step-by-step installation and configuration guide
**Tone:** Helpful, instructional, clear
**Target Audience:** WordPress site owners, community managers

---

## Script

### INTRO (0:00 - 0:20)

**VISUAL:** Plugin logo and title card

**NARRATOR:**
"In this tutorial, I'll show you how to install and configure BuddyPress Group Reviews on your WordPress site. We'll cover installation, setting up your rating criteria, configuring moderation, and customizing the display. Let's get started."

**ON-SCREEN TEXT:** "BuddyPress Group Reviews - Setup Tutorial"

---

### REQUIREMENTS (0:20 - 0:40)

**VISUAL:** Requirements checklist

**NARRATOR:**
"Before we begin, make sure you have WordPress 6.0 or higher, PHP 7.4 or higher, and BuddyPress 12 or higher with the Groups component active. The plugin also works with BuddyBoss Platform."

**ON-SCREEN TEXT:**
- WordPress 6.0+
- PHP 7.4+
- BuddyPress 12.0+ (Groups active)
- OR BuddyBoss Platform

---

### INSTALLATION (0:40 - 1:20)

**VISUAL:** WordPress admin > Plugins > Add New

**NARRATOR:**
"To install, go to Plugins, then Add New in your WordPress admin."

**VISUAL:** Search field, typing "BuddyPress Group Reviews"

**NARRATOR:**
"Search for 'BuddyPress Group Reviews' or 'Review BuddyPress Groups.'"

**VISUAL:** Plugin card in search results

**NARRATOR:**
"Find the plugin by Wbcom Designs and click Install Now."

**VISUAL:** Install button, then Activate button

**NARRATOR:**
"Once installed, click Activate. You'll be redirected to the plugin settings automatically."

**ON-SCREEN TEXT:** "Installation complete!"

---

### GENERAL SETTINGS (1:20 - 2:20)

**VISUAL:** Plugin settings page - General tab

**NARRATOR:**
"Let's start with the General settings. Here you'll configure the core behavior of the plugin."

---

**VISUAL:** Multiple Reviews toggle

**NARRATOR:**
"First, decide if members can submit multiple reviews for the same group. Toggle this on if you want members to update their feedback over time."

**ON-SCREEN TEXT:** "Multiple Reviews: On or Off"

---

**VISUAL:** Auto-Approve toggle

**NARRATOR:**
"Next, the auto-approval setting. When enabled, reviews publish immediately without moderation. For most communities, I recommend keeping this off so group admins can review submissions first."

**ON-SCREEN TEXT:** "Auto-Approve: Recommended OFF"

---

**VISUAL:** Reviews per page setting

**NARRATOR:**
"Set how many reviews display per page before pagination kicks in. The default of 10 works well for most sites."

---

**VISUAL:** Notifications toggle

**NARRATOR:**
"Enable BuddyPress notifications to alert group admins when new reviews are submitted. This requires the Notifications component to be active."

---

**VISUAL:** Activity toggle

**NARRATOR:**
"Enable review activity to post reviews to the activity stream. Great for visibility, but remember that private group reviews will only show in the group's activity."

---

**VISUAL:** Exclude groups dropdown

**NARRATOR:**
"Finally, if you have groups that shouldn't have reviews—like admin or test groups—select them here to exclude them."

**VISUAL:** Click Save Settings

**NARRATOR:**
"Click Save Settings when you're done."

---

### CRITERIA SETTINGS (2:20 - 3:00)

**VISUAL:** Criteria tab

**NARRATOR:**
"Now let's set up your rating criteria. Click on the Criteria tab."

**VISUAL:** Default criteria visible

**NARRATOR:**
"You can add as many criteria as you like. Click 'Add Review Criteria' to create a new one."

**VISUAL:** Adding new criterion

**NARRATOR:**
"Type your criterion name—like 'Communication' or 'Helpfulness.' Each criterion will show up as a separate star rating on the review form."

**VISUAL:** Toggle to enable/disable

**NARRATOR:**
"Use the toggle to enable or disable individual criteria. Disabled criteria won't appear on the form but the data is preserved."

**VISUAL:** Drag to reorder

**NARRATOR:**
"Drag the handles to reorder how criteria appear. Save your settings when done."

**ON-SCREEN TEXT:** "Custom criteria = Better feedback"

---

### DISPLAY SETTINGS (3:00 - 3:30)

**VISUAL:** Display tab

**NARRATOR:**
"In the Display tab, you can customize labels and colors."

**VISUAL:** Label fields

**NARRATOR:**
"Change 'Review' and 'Reviews' to whatever terminology fits your community—like 'Feedback' or 'Testimonials.'"

**VISUAL:** Color picker

**NARRATOR:**
"Choose a star color that matches your site's branding. The default gold works well, but you can pick any color."

**VISUAL:** Save and preview

**NARRATOR:**
"Save your settings and the changes apply throughout the plugin."

---

### EMAIL SETTINGS (3:30 - 4:00)

**VISUAL:** Emails tab

**NARRATOR:**
"The Emails tab lets you customize notification emails. You have three email types: new submissions to group admins, approval notifications to reviewers, and denial notifications."

**VISUAL:** Enable toggles

**NARRATOR:**
"Toggle each email type on or off based on your needs."

**VISUAL:** Subject and message fields

**NARRATOR:**
"Customize the subject line and message content. Use placeholders like [group-name] and [user-name] to personalize each email."

**VISUAL:** Save settings

**NARRATOR:**
"Save when you're done."

---

### TESTING (4:00 - 4:30)

**VISUAL:** Frontend group page

**NARRATOR:**
"Let's test the setup. Go to a group on the frontend and you should see the Reviews tab."

**VISUAL:** Click Reviews tab

**NARRATOR:**
"Click it, and you'll see the review form with your custom criteria."

**VISUAL:** Submit a test review

**NARRATOR:**
"Submit a test review. If auto-approval is off, it goes to moderation. Check the Manage tab to approve it."

**VISUAL:** Approved review displayed

**NARRATOR:**
"Once approved, the review appears publicly. Perfect!"

**ON-SCREEN TEXT:** "Setup complete!"

---

### OUTRO (4:30 - 4:50)

**VISUAL:** Plugin logo and links

**NARRATOR:**
"That's it! BuddyPress Group Reviews is now configured and ready to collect member feedback. For more help, check out our documentation at wbcomdesigns.com. Thanks for watching!"

**ON-SCREEN TEXT:**
- "Documentation: wbcomdesigns.com"
- "Support: wbcomdesigns.com/support"

---

## Production Notes

### Visual Style
- Screen recording of actual WordPress admin
- Mouse movements should be slow and deliberate
- Highlight or zoom on important elements
- Use callouts/arrows for key clicks

### Recording Requirements
- Clean WordPress install with BuddyPress
- Plugin installed and activated
- At least 3 test groups created
- Test user accounts for review submission
